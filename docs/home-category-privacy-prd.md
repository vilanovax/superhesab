# PRD: فاز ۲ — حریم خصوصی دسته در دفتر خانه

## هدف

در دفتر **خانه** (`FAMILY`)، اعضا بتوانند برخی دسته‌ها را **خصوصی** کنند تا طرف مقابل آن‌ها را نبیند و نتواند در آن دسته ثبت کند. بقیهٔ دسته‌ها **مشترک** می‌مانند (رفتار فاز ۱).

## خارج از اسکوپ این فاز

- اشتراک انتخابی با زیرمجموعهٔ اعضا (فقط SHARED برای همه vs PRIVATE برای یک نفر)
- حریم روی `categoryLabel` سفارشی (دستهٔ آزاد همیشه مشترک)
- فورک جدول Expense

## مدل

```
SpaceCategoryPolicy
  spaceId + category (unique)
  visibility: PRIVATE فقط ذخیره می‌شود؛ نبود ردیف = SHARED
  ownerUserId: کسی که دسته را خصوصی کرده
```

### قوانین

| حالت | دیدن تراکنش آن دسته | انتخاب در فرم |
|------|---------------------|----------------|
| SHARED (پیش‌فرض) | همهٔ اعضا | همهٔ EDITOR/OWNER |
| PRIVATE | فقط `ownerUserId` (+ OWNER فضا همیشه می‌بیند برای نظارت؟) | فقط `ownerUserId` |

**تصمیم محصول:** OWNER فضا همیشه همهٔ دسته‌ها را می‌بیند (برای مدیریت خانه). EDITOR فقط SHARED + PRIVATE مال خودش.

VIEWER: فقط SHARED (+ PRIVATE خودش اگر داشته باشد؛ معمولاً ندارد).

حداکثر یک مالک خصوصی per `(spaceId, category)`.

## UI

- تنظیمات دفتر خانه: بخش «دسته‌های خصوصی / مشترک»
- سوئیچ per دسته (هزینه + درآمد)
- توضیح کوتاه: «خصوصی = فقط تو می‌بینی؛ مشترک = همه»
