# Nginx — superhesab.ir

- `superhesab.ir.conf` → لندینگ استاتیک (`/home/superhesab/landing`)
- `app.superhesab.ir.conf` → پروکسی به اپ روی `:3003`
- `ssl-superhesab.conf` → وایلدکارت `*.superhesab.ir` + `superhesab.ir`

گواهی روی سرور: `/etc/ssl/superhesab.ir/{fullchain,privkey}.pem` (در گیت نیست).
